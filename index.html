Desativar Proteção de Áudio (ROOT)

Guia definitivo para remoção do aviso de volume seguro em TV Box Android

Método Desenvolvido por Diniz-RF

1. Baixe o SDK Platform Tools

Acesse o link oficial para baixar as ferramentas ADB:

https://developer.android.com/tools/releases/platform-tools

Extraia o arquivo compactado em seu computador, abra o Prompt de Comando (CMD) dentro da pasta extraída e execute os comandos a seguir.

2. Conecte o Dispositivo

Primeiro, encerre servidores ADB anteriores e conecte o dispositivo via IP (substitua pelo IP real da sua TV Box):

.\adb kill-server
.\adb connect IP-DA-BOX

3. Obtenção de Acesso Root

Execute a sequência para reiniciar o adb em modo root, remontar a partição e entrar no shell do sistema:

.\adb root
.\adb remount
.\adb shell

4. Elevação de Privilégios (SU)

Dentro do prompt interativo do ADB shell, digite o comando para assumir o superusuário:

su

5. Criação da Pasta, Script e Execução de Teste

No terminal do dispositivo (já com privilégios su), execute o bloco para criar o diretório, gravar o script de monitoramento, conceder permissões e iniciar o processo:

mkdir -p /system/etc/init.d
printf '#!/system/bin/sh\nuntil [ "$(getprop sys.boot_completed)" = "1" ]; do sleep 2; done\nwhile true; do\nST=$(settings get global audio_safe_volume_state)\nif [ "$ST" != "1" ]; then\nsettings put global audio_safe_volume_state 1\nsettings put global safe_media_volume_enabled 0\nfi\nsetprop audio.safemedia.bypass true\nsleep 4\ndone &\n' > /system/etc/init.d/disable_safe_volume.sh
chmod 755 /system/etc/init.d/disable_safe_volume.sh
/system/etc/init.d/disable_safe_volume.sh

6. Configuração do Gancho de Boot (Install Recovery)

Crie o script de inicialização automática no recovery do sistema:

printf '#!/system/bin/sh\n/system/etc/init.d/disable_safe_volume.sh &\n' > /system/etc/install-recovery.sh

7. Permissões do Gancho de Inicialização

Conceda permissão de execução ao arquivo de boot:

chmod 755 /system/etc/install-recovery.sh

8. Cópia de Segurança para a Pasta Bin

Duplique o script para a pasta bin do sistema para garantir compatibilidade com diferentes ROMs:

cp /system/etc/install-recovery.sh /system/bin/install-recovery.sh
chmod 755 /system/bin/install-recovery.sh

9. Reinicialização

Por último, reinicie o aparelho para aplicar todas as modificações permanentemente:

reboot

Verificação Pós-Boot: Após reiniciar a TV Box, abra novamente o terminal e verifique se o retorno do estado do volume é 1:

.\adb shell settings get global audio_safe_volume_state
